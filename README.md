# PPT 图片字体批量替换

纯前端、本地运行、不联网的 PPT（.pptx）批量处理工具。直接改写文件内部的图片与 XML，版式、位置、动画、引用关系一概不动，原文件不修改，只生成一份新文件。

## 功能
- **图片替换**：单张 / 多素材批量（轮换 / 随机分配），裁切铺满 / 完整留白 / 拉伸，JPEG 质量可调；矢量图自动跳过。
- **字体替换**：思源黑体 / 思源宋体 / 微软雅黑 / 等线 / HarmonyOS Sans SC 等可选，自定义字体名，标题黑体·正文宋体智能判断。
- **年份替换**：不替换 / 20—26 随机 / 指定年份。
- **文本批量替换**（v9 新增）：多行规则 `旧文本 => 新文本`，只改正文文字，可选区分大小写。
- **主题配色替换**（v9 新增）：逐色把 PPT 里的颜色统一改成新色。
- **批量处理**：多份 PPT 套用同一套规则，打包成 zip 下载。
- **暗色模式**：右上角一键切换，记忆偏好。

## 使用方法
1. 用 **Chrome / Edge**（或较新 Safari）打开 `scripts/ppt-replacer.html`。
2. 拖入 `.pptx`，按步骤设置规则。
3. 点「生成新文件」下载 `*_替换.pptx`（批量模式为 zip）。

> 字体仅修改引用名、不嵌入文件；交付前建议在 PowerPoint 勾选「文件 → 选项 → 保存 → 将字体嵌入文件」。

## 技术说明
- 纯 HTML + CSS + 原生 JS，单文件零依赖。
- 自实现 ZIP 读写（store / deflate），原地改写 pptx 内部部件，保留结构与顺序。
- 图片用 Canvas 按原图尺寸重绘后写回，图片框位置大小不变。
- 文本改写后用 DOMParser 做 XML 合法性校验，异常即中止并提示，不产出损坏文件。
