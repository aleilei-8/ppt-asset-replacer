# PPT 图片字体批量替换 · 使用文档

纯前端单文件工具，本地运行、不联网、不修改原文件。生成的新文件名为 `<原名>_替换.pptx`。

## 快速开始
1. 用 Chrome / Edge 打开 `scripts/ppt-replacer.html`。
2. 将 `.pptx` 拖入「选择 PPT 文件」区域（或点击选择）。
3. 页面自动解析：显示页数、图片数（可替换数）、字体数、文本段数、颜色数。
4. 依次设置要改的项（图片 / 字体 / 年份 / 文本 / 配色），不填的项不改。
5. 点底部「生成新文件」下载结果。

## 功能详解

### 1. 图片替换
- **单张替换**：在图片清单里点某张图的「选择新图」，挑一张本地图片替换。
- **多张素材批量**：点「多张素材批量替换」选若干素材图，再选「轮换分配 / 随机分配」，工具自动把素材循环分配给所有可替换图片。「重新分配」可换一种随机结果。「全部换成同一张」则所有图用同一素材。
- **适配方式**（选项卡片）：
  - 裁切铺满：新图按比例放大填满原图框，超出部分裁掉（默认）。
  - 完整留白：新图完整显示，四周用底色补齐。
  - 拉伸变形：直接拉伸到原图框尺寸（可能变形）。
- **留白底色**：选「完整留白」时生效，可选白/黑/浅灰。
- **JPEG 质量**：60–100，默认 92。

> 矢量图（.emf/.wmf）浏览器无法解码，自动跳过并标注「矢量图，浏览器无法处理」。

### 2. 字体替换
- 「全部 → 思源黑体 / 思源宋体」：一键统一。
- 「标题黑体 / 正文宋体（自动判断）」：按字体名特征自动分流（含黑/雅黑/gothic/arial 等归黑体；含宋/serif/times/楷 等归宋体）。判断不出的会提示手动填。
- 也可在字体清单里逐条选目标字体，或选「其他字体（手动输入）」填任意字体名（如 微软雅黑）。
- **连符号字体一起换**：默认不勾。勾上会把 Wingdings 这类负责项目符号小图标的字体也换掉，可能导致图标变形，一般不勾。

### 3. 年份替换
- 不替换 / 20—26 随机 / 指定年份。
- 随机模式下，同一个旧年份统一映射到同一个新年份（不会一份文件里同一年出现两种结果）。「重新随机」可换一组映射。

### 4. 文本批量替换（新增）
- 点「+ 添加规则」，每行一条：`旧文本 => 新文本`。
- 例：`旧公司名称 => 新公司名称`，可加多条（公司名、产品名、电话、网址等）。
- 新文本留空 = 删除该文字。
- 「区分大小写」勾选后，`Apple` 不会匹配 `apple`。
- 只替换正文文字（`<a:t>` 内），不动标签与属性，安全。

### 5. 主题配色替换（新增）
- 页面列出 PPT 里出现的所有颜色（按出现次数排序）。
- 在每行右侧输入框填目标色（十六进制，如 `#C0392B`，不区分大小写），即可把该旧色统一改成新色。
- 适合把模板蓝主色整体改成品牌红等。

### 6. 批量处理（多份）
- 顶部切到「批量处理（多份）」。
- 拖入或选择多个 `.pptx`。
- 在「批量规则」里统一设置：图片素材及分配方式、目标字体、年份方式。
- 文本替换与配色规则沿用上方已设置的规则（单份模式下设好即可）。
- 点「批量生成新文件」，所有结果打包成一个 zip 下载。

### 7. 暗色模式
- 右上角「🌙 暗色 / ☀️ 亮色」一键切换，偏好记在浏览器本地，下次自动恢复。

## 常见问题
- **字体改了但对方电脑显示不对？** 字体只改引用名、不嵌入文件。交付前在 PowerPoint 勾选「文件 → 选项 → 保存 → 将字体嵌入文件」。
- **图片被拉扁？** 不会。新图按原图像素尺寸重绘，图片框位置大小不变；若想完整显示小图可选「完整留白」。
- **某些图没被替换？** 多为矢量图（.emf/.wmf），浏览器无法处理，已自动跳过并提示。
- **打开没反应？** 需用较新的 Chrome / Edge / Safari，旧浏览器缺 CompressionStream 能力会被提示。
