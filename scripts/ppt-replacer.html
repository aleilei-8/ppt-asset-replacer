PPT 图片与字体批量替换

换掉整份 PPT 里的图片、把字体统一改成思源黑体或思源宋体。版式、位置、动画、引用关系一概不动。

当前浏览器不支持本工具所需的能力（CompressionStream）。请改用 Chrome / Edge 打开，或用较新版本的 Safari。

文本批量替换

每行一条规则，格式 旧文本 => 新文本（旧新之间用 => 分隔）。例：旧公司 => 新公司。新文本留空表示删除该文字。只替换正文文字（<a:t>），不碰标签与属性。
6

主题配色替换

把 PPT 里出现的颜色（srgbClr）统一改成新色，例如把蓝色主色改成品牌红。点右侧色块可手动输入十六进制（如 #C0392B）。
7

选项

一般不用改
先选一份 PPT 文件。

三点说明

  • 字体只是把"引用名"改掉，不会嵌进文件。对方电脑没装该字体会回退显示，交付前建议在 PowerPoint 里勾选「文件 → 选项 → 保存 → 将字体嵌入文件」。
  • 新图会先按原图的像素尺寸重新处理再写回去，所以幻灯片里的图片框位置、大小完全不变，不会出现图片被拉扁。
  • 矢量图（.emf / .wmf）浏览器读不了，会被跳过并提示，其余图片照常替换。
  • 文件只在你自己的电脑里处理，全程不联网、不上传。生成的是一份新文件，原文件不动。
